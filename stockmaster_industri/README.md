StockMaster Industri

Deskripsi

StockMaster Industri adalah aplikasi berbasis Flutter Web untuk mengelola persediaan barang industri. Aplikasi ini dibuat untuk memenuhi tugas mata kuliah Mobile Programming dengan materi State dan Interaksi Pengguna.

Fitur

- Menampilkan daftar barang dan jumlah stok.
- Menambahkan barang baru.
- Menambah dan mengurangi jumlah stok.
- Menghapus barang dengan konfirmasi.
- Menampilkan total stok dan jumlah jenis barang.
- Memberikan validasi pada input barang dan stok.
- Memperbarui tampilan secara otomatis saat data berubah.

Teknologi

- Flutter
- Dart
- StatefulWidget
- setState()
- TextField dan interaksi pengguna

Cara Menjalankan

1. Pastikan Flutter sudah terinstal.
2. Buka terminal di folder project.
3. Jalankan perintah berikut:

flutter pub get
flutter run -d chrome

Materi yang Diterapkan

Aplikasi menerapkan State dan Interaksi Pengguna melalui perubahan data menggunakan "setState()", input barang melalui form, serta callback pada tombol tambah, pengurangan stok, dan penghapusan barang.
